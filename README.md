Visito is a cross-platform mobile application built with Xamarin.Forms for both Android and iOS, utilizing the MVVM (Model-View-ViewModel) architecture for efficient and maintainable code structure.

The application allows you to record your experience that you had at a nearby venue. I have used the authentication service provided by Google's firebase and Firebase Firestore to store data in documents,
which are organized into collections.  
I am also using foursquare API version 3 that provides me all the prominent venues within a certain radius and by using that information, display pins at that location on Maps, 
(with all the details of the experience) for which I am using Google Maps Platform which is a set of tools and APIs that helps us add a map, location and provide navigations.
